عجلة الصف التاسع - الكيمياء | الفصلان الدراسيان
=====================================================

المحتوى:
- الفصل الأول: ١٩ درسًا، مجموعها ٩٤١ سؤالًا، ملفات تبدأ بـ s1-questions-lesson-01.js إلى s1-questions-lesson-19.js.
- الفصل الثاني: ١٥ درسًا، محفوظة كما كانت في مشروعك الأصلي، ملفات questions-lesson-01.js إلى questions-lesson-15.js.
- students.js: أسماء ٢١٧ طالبًا من ست شعب، مشتركة في الفصلين.

طريقة التشغيل دون إنترنت:
1. فك ضغط هذا الملف مع الاحتفاظ بجميع الملفات في مجلد واحد.
2. افتح index.html في المتصفح.
3. اختر الفصل الدراسي ثم الشعبة ثم الدرس واضغط ابدأ العجلة.

طريقة تحديث المشروع في GitHub:
1. ارفع جميع الملفات في هذا المجلد إلى جذر المستودع واستبدل index.html وscript.js وstyle.css.
2. احتفظ بملفات الفصل الثاني القديمة؛ هي متضمنة هنا دون تغيير.
3. لأن الموقع يعتمد ملفات JavaScript مستقلة، يجب أن تتطابق أسماء الملفات مع المسارات داخل index.html.

بديل أسهل لمن سبق أن رفع المشروع: توجد حزمة grade9_easy_update.zip فيها ثلاثة ملفات فقط للتغيير/الإضافة:
- index.html
- script.js
- questions-semester1.js (يجمع أسئلة الدروس ١٩ في ملف واحد)
ويظل style.css وأسماء الطلاب وملفات الفصل الثاني في GitHub كما هي.

تنبيه: إذا كان GitHub المستودع أو الموقع متاحًا للعامة فستكون أسماء الطلاب في students.js قابلة للاطلاع؛ راعِ خصوصيتهم.

ملاحظات بنية الملفات ومصدر الأسئلة في SOURCE_REVIEW.txt.
